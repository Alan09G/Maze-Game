To run this game you need to install: 

pip install pygame PyOpenGL PyOpenGL_accelerate

and then run main.py. All files should be kept in the same folder. 


CONTROLS

move: WASD
camera: mouse
sprint (with stamina): SHIFT
jump (using powerup): SPACE
restart (after finishing): R
quit: ESC


GOAL

Reach the glowing green tile to win.
